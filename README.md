# Anima

Моды для Minecraft под Forge. Общий замысел один: **мир должен быть живым** — не декорацией
вокруг игрока, а средой, которая живёт своим чередом и замечает, что игрок в ней есть.

Мод — это не набор предметов, а поведение: зверь, у которого свои дела, растение со своим
норовом, событие, которое приходит само и уходит само. Ванильный дух при этом не ломается:
всё новое должно выглядеть так, будто оно тут и было.

## Ядро и моды

Репозиторий устроен из двух частей:

- **Anima Core** — ядро. Общие утилиты, каркас конфигов, общий экран настроек, общие теги и
  шина мировых событий. Своего контента — ни мобов, ни блоков, ни предметов — в ядре нет.
- **Моды** — каждый про одну механику, со своим `mod_id`, своей версией и своим jar.

Ядро — **обязательная зависимость** каждого мода и ставится отдельным файлом: внутрь модов
оно не вкладывается. Игрок скачивает Anima Core и те моды, которые ему нужны, — хоть один,
хоть все. Если ядра не окажется, Forge сам скажет об этом внятным сообщением.

Правило связей простое и нарушать его нельзя:

> **мод → ядро можно, мод → мод нельзя.**

Каждый мод работает сам по себе и ничего не знает о соседях. Взаимодействуют они только
через ядро: мод шлёт сигнал в общую шину, а кто на него отзовётся — не его забота. Поэтому
любой мод можно поставить в одиночку, а вместе они складываются в общий живой мир.

Из этого же следует дисциплина версий: внутри мажорной версии ядро только дополняется.
Ничего не переименовывается и не удаляется — иначе у игроков соберётся зоопарк из старых
модов и нового ядра.

## Установка

1. Forge нужной версии
2. **Anima Core**
3. любые моды семейства — по вкусу

Всё это кладётся в папку `mods/`.

## Структура

```
core/     ядро
<группы>/ моды, разложенные по смыслу
```

Классы лежат в `com.pwsayp.*`.
